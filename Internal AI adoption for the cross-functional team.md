# Internal AI adoption for a cross-functional team.


From individual practices to one shared way of working with Claude.
--

## Overview
A small cross-functional team adopted Claude Cowork without a shared setup or documented practices. Technical skill varied widely, prompting was inconsistent, and the knowledge base was not kept up to date.

**Focus:** Role-based onboarding, clear task ownership, and a pre-delivery quality check for client-facing work.

**Approach:** Team interviews → use-case and workflow mapping → role-based documentation. 
I mapped use cases by role and project stage, then built the documentation around roles rather than tool features.


## Documentation Deliverables

| Deliverable | What it gave the team |
|---|---|
| **Setup guide** | A role-specific path: what to set up and what to do next |
| **Responsibility map** | Clear task ownership, including who maintains the shared Claude knowledge base |
| **Use-case walkthrough** | A real project task shown step by step |
| **Troubleshooting guide** | A clear route when something breaks |
| **Pre-delivery checklist** | What to verify before AI-assisted work goes to a client |



**Setup guide: role-specific onboarding paths.**

Onboarding matrix based on the users role and technical level. 

*Example: Founder vs. Graphic designer*

Founder path: Review an existing client proposal → open the relevant project knowledge base → use the approved prompt for a project update → review the draft against the client brief → send for final approval. No changes to the shared knowledge base.

Graphic Designer path: Open the project workspace → check the current brand and asset guidelines → use the approved image-generation workflow → review generated assets against brand requirements → save approved assets to the project library.

**Responsibilities map.**

*Owner* - responsible for current version and updates on time. 
*Contributes* - provides input.
*Final sign-off* - approves final version for clients. 

| Task or area | Founder | Account Manager | Growth strategist | Graphic designer |
| --- | --- | --- | --- | --- |
| Shared knowledge base | Owner | Contributes | Contributes | Contributes |
| Client voice and tone | Contributes | Owner | Contributes |  |
| Brand guidelines | Contributes |  |  | Owner |
| Prompt libraries | Contributes | Owner | Owner | Owner |
| Pre-delivery checklist | Final sign-off | Owner | Owner | Owner |


## Outcome
The team moved from individual practices to a documented, role-based workflow with defined responsibilities, consistent guidance, and a shared approach to reviewing client-facing work.
